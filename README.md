# Clothing Shop 🛍️

A Flutter-based clothing shopping application with interactive product cards and animated product details.

## About the Project

Clothing Shop is a mobile application designed to provide users with an interactive shopping experience. It features a product discovery feed, user stories, animated product presentations, and an interactive price offer interface.

## Features

- Interactive product cards with swipe navigation
- User stories section
- Animated product transitions
- Product details with image gallery and thumbnail previews
- Hero animations between product screens
- Expandable bottom sheet for price offers
- Custom numeric keypad for entering price offers
- Interactive swipe-to-submit offer button
- Responsive UI for different screen sizes
- Smooth animations and transitions

## Tech Stack

- **Framework:** Flutter
- **Language:** Dart
- **Icons:** Eva Icons
- **Animations:** Flutter Animation Framework
- **UI Components:** Material Design

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/amirrezanadali01/ClothingShop.git
   ```

2. Navigate to the project directory:

   ```bash
   cd clothing_shop
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
